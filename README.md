1. Dominio en lo de  Actores

Usuario: almacena nombre,  el correo,  el teléfono,la  dirección y la  contraseña.

Repartidor: almacena nombre,el  teléfono,la placa del vehículo y la disponibilidad.

2. Dominio en los  Catálogo

Restaurante: registra nombre, la  dirección,el  teléfono, la categoría y  el estado.

Plato: almacena el restaurante asociado, el  nombre,  la escripción,  el precio y la  disponibilidad.

3. Dominio  Transaccional

Pedido: registra usuario,  el restaurante, el repartidor, la fecha, la dirección de entrega, el estado y  el total.

Detalle_Pedido: registra el pedido, el plato, la cantidad y el precio unitario.
